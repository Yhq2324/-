# 汽车仿真教学软件开发项目
## Claude + Codex 协作开发模式

> **项目架构：** Claude（总设计+编程）→ GitHub（代码库）→ Codex（执行者）
> 
> **开发周期：** 4-6个月
> 
> **技术栈：** Blender + UE5.5 + C++ + Python

---

## 📋 项目概述

本项目采用AI双引擎协作模式开发汽车仿真教学软件：

- **Claude AI（我）：** 总设计师、程序架构师、代码编写者
- **Codex AI：** 执行引擎、任务处理者、资产生成者
- **开发者（您）：** 需求方、审核者、最终集成者

## 🔄 工作流程

### 阶段0：项目初始化（当前阶段）

**Claude的任务：**
- [x] 创建项目结构
- [ ] 编写完整的Blender自动化脚本
- [ ] 编写UE5 C++核心代码
- [ ] 编写配置文件
- [ ] 编写执行文档
- [ ] 提交到GitHub

**Codex的任务：**
- [ ] 等待Claude完成代码
- [ ] 从GitHub拉取代码
- [ ] 验证环境配置

**开发者的任务：**
- [ ] 审核Claude的设计方案
- [ ] 准备点云数据

---

### 阶段1：点云处理Pipeline（Week 1-2）

**Claude的任务：**
1. 编写点云分析脚本（`01_点云分析.py`）
2. 编写点云清洗脚本（`02_点云清洗.py`）
3. 编写网格转换脚本（`03_点云转网格.py`）
4. 编写优化脚本（`04_模型优化.py`）
5. 提交代码到GitHub
6. 创建详细的`Codex执行指南.md`

**Codex的任务：**
1. 从GitHub克隆最新代码
2. 读取`点云数据/`目录下的所有点云文件
3. 执行`01_点云分析.py` → 生成分析报告
4. 执行`02_点云清洗.py` → 清洗点云
5. 执行`03_点云转网格.py` → 生成网格模型
6. 执行`04_模型优化.py` → 优化模型
7. 将结果输出到`输出/模型/`
8. 生成执行日志到`输出/日志/`

**开发者的任务：**
1. 将点云文件放入`点云数据/`目录
2. 审查Codex生成的模型质量
3. 反馈问题给Claude调整脚本

---

### 阶段2：UE5核心系统（Week 3-6）

**Claude的任务：**
1. 编写C++交互系统代码
2. 编写Blueprint逻辑
3. 编写相机控制系统
4. 编写UI系统
5. 提交代码到GitHub
6. 编写集成文档

**Codex的任务：**
1. 从GitHub拉取UE5代码
2. 编译C++代码
3. 导入Blueprint到项目
4. 生成项目文件报告

**开发者的任务：**
1. 在UE5中导入Codex生成的模型
2. 应用Claude的C++和Blueprint代码
3. 测试功能
4. 反馈给Claude

---

### 阶段3：内容制作（Week 7-16）

**Claude的任务：**
1. 编写批量导入脚本
2. 生成教学文本内容
3. 设计场景布局脚本
4. 提交到GitHub

**Codex的任务：**
1. 执行批量处理所有点云
2. 生成所有模型和贴图
3. 自动化材质设置
4. 生成资产清单

**开发者的任务：**
1. 在UE5中组装场景
2. 调整视觉效果
3. 测试交互流程
