# 项目总览

> **项目名称：** 汽车仿真教学软件
> 
> **开发模式：** Claude（设计+编码）→ GitHub → Codex（执行）
> 
> **开发周期：** 4-6个月
> 
> **当前状态：** 🟡 初始化中

---

## 🎯 项目目标

开发一款类似样品软件的汽车仿真教学应用，具备：
- 3D可视化展示
- 交互式部件拆装
- 教学说明和动画
- 多场景切换

**核心特点：**
- 从点云数据开始
- 使用UE5.5 + Blender
- AI双引擎协作开发
- 一人完成所有工作

## 🛠️ 技术栈

### 3D处理
- **Blender 3.x+** - 点云处理、建模、烘焙
- **Python 3.8+** - 自动化脚本
- **CloudCompare** - 点云预处理（可选）

### 游戏引擎
- **Unreal Engine 5.5** - 主引擎
- **C++17** - 系统代码
- **Blueprint** - 逻辑编程

### 开发工具
- **Visual Studio Code** - Python编辑
- **Visual Studio 2022** - C++编译
- **Git/GitHub** - 版本控制

### AI工具
- **Claude AI** - 设计和编程
- **Codex AI** - 任务执行
