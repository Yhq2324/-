**目标：** 分析`点云数据/`目录下的所有点云文件

```bash

ls -lh 点云数据/
```

### 任务1.2：清洗点云数据

**前提条件：** 任务1.1完成，已有分析报告

**目标：** 清洗所有点云，去噪、降采样

**执行步骤：**

```bash
# 创建清洗后的输出目录
mkdir -p 点云数据/已清洗

# 对每个点云执行清洗
# 根据分析报告决定降采样比例
for file in 点云数据/*.ply; do
    filename=$(basename "$file" .ply)
    echo "清洗: $file"
    
    # 默认降采样50%
    blender --background --python 脚本/blender/02_点云清洗.py -- \
        "$file" \
        "点云数据/已清洗/${filename}_cleaned.ply" \
        --downsample 0.5
done
```

**高级：根据分析报告自动调整参数**

```bash
# 如果点数>1000万，降采样到30%
# 如果点数100万-1000万，降采样到50%
# 如果点数<100万，降采样到80%

# 你需要读取分析报告JSON，判断点数，然后调整参数
# 示例Python脚本会在下个版本提供
```

**预期输出：**
- ✅ `点云数据/已清洗/` 目录下的清洗后点云文件
- ✅ `输出/日志/` 目录下的处理日志
- ✅ 每个文件的点数减少报告

**完成标志：**
```bash
ls -lh 点云数据/已清洗/
# 应该看到所有 *_cleaned.ply 文件
```

## 🔧 故障排查

### 问题1：Blender命令找不到

```bash
# 检查Blender安装路径
which blender

# 如果未找到，使用完整路径
/Applications/Blender.app/Contents/MacOS/Blender --version

# 或创建别名
alias blender="/Applications/Blender.app/Contents/MacOS/Blender"
```

### 问题2：点云文件导入失败

**可能原因：**
- 文件格式不支持
- 文件损坏
- 编码问题

**解决方案：**
1. 检查文件扩展名
2. 尝试用其他工具打开验证
3. 转换格式（如果需要）
4. 将错误记录到执行报告

### 问题3：内存不足

**现象：** Blender崩溃或卡死

**解决方案：**
1. 分批处理（不要一次处理所有文件）
2. 增加降采样比例
3. 关闭其他应用
4. 使用`--background`模式（已使用）
